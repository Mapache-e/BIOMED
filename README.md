# BIOMED

## Descripción
Proyecto académico de gestión de versiones y configuraciones de parámetros clínicos simulados para BIOMED S.A.C.

## Objetivo
Implementar control de versiones y procesos de integración y entrega continua (CI/CD) mediante GitHub Actions.

## Tecnologías
- Git y GitHub
- GitHub Actions
- JSON
- XML
- Python para validaciones automáticas

## Alcance
El proyecto utiliza datos ficticios con fines educativos. No está destinado al diagnóstico ni al uso clínico real.
